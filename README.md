# PakTech storefront

A responsive static e-commerce storefront for PakTech, a Pakistan-focused consumer electronics brand.

## Run locally

No build step is required. Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Responsive PakTech homepage
- Product cards and PKR pricing
- Functional client-side cart drawer
- Quantity controls and demo checkout action
- Categories, benefits, reviews, FAQ, and footer

This is a frontend demo. Connect the cart and checkout buttons to Shopify, WooCommerce, Stripe, or your preferred backend before accepting live orders.
